# REVORA

## 1. Project Name
REVORA - AI Revenue Recovery Agent

## 2. Hackathon Track
Track 03 — AI Revenue Recovery

## 3. Problem Statement
Merchants lose revenue because of failed payments, checkout abandonment, failed subscriptions, and overdue receivables.

## 4. Proposed Solution
REVORA detects revenue at risk, diagnoses the likely reason, recommends the most effective recovery intervention, validates the action against merchant policies, executes a bounded recovery workflow, measures recovered revenue, and maintains a complete audit trail.

## 5. Planned Technology Stack
- **Frontend**: React + Vite + TypeScript
- **Styling**: Tailwind CSS
- **Backend**: FastAPI + Python
- **Database**: PostgreSQL / Supabase
- **AI**: LLM API (to be configured)
- **Payment Integration**: Razorpay Test Mode APIs (to be configured)
